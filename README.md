## 🧰 What is DebugSwift?

DebugSwift is a simple set of tools designed to help you find and fix problems in iOS apps. Whether an app crashes, runs slowly, or acts strange, DebugSwift gives clear information to understand what is going wrong. It works with common iOS technologies like UIKit and Swift, even with the latest Swift 6 version. 

You don’t need programming skills to use DebugSwift. It collects and shows data about how the app runs so you can decide what to do next.

---

## 🔍 Key Features

- **Crash Reporting:** See what caused an app to stop unexpectedly.
- **Performance Analysis:** Track what parts slow down or freeze.
- **Memory Leak Detection:** Find parts that use more memory than they should.
- **Log Collection:** Gather detailed logs to understand app activity.
- **Network Monitoring:** Watch data sent and received by the app.
- **UI Layout Debugging:** Check if the app’s user interface displays correctly.
- **Sandbox Insights:** Learn what files the app uses and changes.
- **Works with CocoaPods:** Easily add DebugSwift to your project.
- **Compatible with Latest iOS and Swift Versions:** Keep up to date with your tools.

## 🔧 How to Use DebugSwift

After installing DebugSwift, follow these steps to start checking your iOS app:

1. **Connect your device:** Plug your iPhone or iPad into your Mac using a USB cable.
2. **Open DebugSwift:** Launch the DebugSwift app from your Applications folder.
3. **Select your app:** DebugSwift will show a list of apps installed on your device. Choose the app you want to check.
4. **Start analysis:** Click “Start Debugging” or a similar button to begin gathering data.
5. **View reports:** Once completed, DebugSwift shows crash reports, memory statistics, UI layouts, and network logs.
6. **Save or share:** You can save the reports as files or send them to a developer if you need help.

## 📋 Understanding the Reports

Here’s what each part of DebugSwift’s report means:

- **Crash Report:** Contains details about why an app stopped running. It includes error messages and precise locations in the code.
- **Performance Report:** Shows which operations took the most time, helping to identify slow areas.
- **Memory Leak Report:** Lists objects that were not released properly and are still using memory.
- **Logs:** A timeline of actions and messages generated when the app runs.
- **Network Data:** Details on the data sent and received by the app over the internet.
- **UI Layout:** Visual and technical info about the layout of screens and elements.

You do not need to interpret all details yourself. These reports help you or a developer understand where the problem lies.
